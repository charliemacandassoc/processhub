## Step 1 — Application submission

- [ ] Application form fully completed
- [ ] Photo ID uploaded (passport or driver's licence)
- [ ] Proof of address uploaded (< 3 months old)
- [ ] Terms and conditions accepted
- [ ] Confirmation email received by customer

## Step 2 — Identity verification

- [ ] Document authenticity check passed
- [ ] Name and DOB match confirmed
- [ ] Fraud watchlist check completed
- [ ] PEP / sanctions screening completed
- [ ] Verification result logged in case system

## Step 3 — Account setup

- [ ] CRM account record created
- [ ] Customer ID and account number assigned
- [ ] Portal access provisioned
- [ ] Welcome email sent to customer
- [ ] Billing profile created
- [ ] Relationship manager notified
- [ ] Account health check script run — all green
